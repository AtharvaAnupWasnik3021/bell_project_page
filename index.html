Boundary-Aware Surrogate Modeling of Finite-Temperature Bell Nonlocality

This project asks whether pointwise surrogate accuracy is enough to recover a physically meaningful Bell-nonlocality boundary. We compare three surrogates of the CHSH landscape of a Heisenberg dimer across six training budgets and ten random seeds.

Atharva Anup Wasnik

Paper (link pending) GitHub Reproducibility Results

Can pointwise accuracy guarantee boundary fidelity?

A surrogate can have low prediction error almost everywhere and still put the decision boundary in the wrong place.

RMSE averages the error over the whole parameter domain. The Bell-nonlocality boundary is a curve, and its location depends on the error in a thin neighborhood of that curve. A localized error, or a flattened landscape near the threshold, can change the average very little while shifting or deleting part of the extracted boundary.

For finite-temperature Bell nonlocality the boundary is the physically meaningful object: it separates thermal states that can violate the CHSH inequality from those that cannot. A surrogate used to map that region should therefore be judged on where it puts the boundary, not only on how close its values are.

We evaluate each surrogate at three levels: pointwise error (RMSE), area-weighted region disagreement, and worst-case boundary distance (Hausdorff), plus a point-level check of a boundary-displacement bound.

Key findings from the repository data

  • Cross-model dissociation. Random Forest (RF) has the lowest mean RMSE from N = 250 upward and the highest mean Hausdorff boundary error at every budget. At N = 2500 with boundary-aware sampling: RMSE 0.030 (RF) vs 0.118 (MLP-data); dH 0.987 vs 0.185.
  • Wedge failure. RF misses the high-field boundary wedge in 20/20 and 20/20 seed × sampling evaluations at N = 1000 and N = 2500 respectively. Both MLP variants recover it in 20/20 at each budget.
  • Correlations. Pooled RMSE vs Hausdorff: ρ = −0.075, p = 0.15, n = 360 (not significant). RMSE vs region disagreement: ρ = 0.559, p = 4.97×10−31.
  • Theorem-bound check. The displacement bound holds in 7,934 of 7,950 point-level checks (99.80%); it is not satisfied in every check.
  • Tsirelson-aware loss (20 seeds). Significantly fewer Tsirelson-bound violations (BH-adjusted p = 6.65×10−7). No significant change in boundary fidelity (all BH-adjusted p ≥ 0.50).

Scope. At N = 50 and N = 100 the MLPs have lower mean RMSE than RF, so “RF has the best RMSE” holds only from N = 250 upward (see the budget-sweep table below). All statements describe this simulator, these three surrogates and these budgets.

Physical setting

The system is a finite-temperature, two-spin isotropic Heisenberg dimer in a uniform field h along z, with J = kB = 1:

H(h)=J(σx ⁣⊗ ⁣σx+σy ⁣⊗ ⁣σy+σz ⁣⊗ ⁣σz)+h(σz ⁣⊗ ⁣1+1 ⁣⊗ ⁣σz)H(h)=J\left(\sigma^x\!\otimes\!\sigma^x+\sigma^y\!\otimes\!\sigma^y+\sigma^z\!\otimes\!\sigma^z\right)+h\left(\sigma^z\!\otimes\!\mathbb{1}+\mathbb{1}\!\otimes\!\sigma^z\right)H(h)=J(σx⊗σx+σy⊗σy+σz⊗σz)+h(σz⊗1+1⊗σz)

The thermal reduced state is the Gibbs state

ρ(T,h)=e−H(h)/kBTTr e−H(h)/kBT\rho(T,h)=\frac{e^{-H(h)/k_BT}}{\mathrm{Tr}\,e^{-H(h)/k_BT}}ρ(T,h)=Tre−H(h)/kB​Te−H(h)/kB​T​

For a two-qubit state, the Horodecki criterion gives the maximal CHSH value over measurement settings. With the correlation matrix and its eigenvalues u1≥u2≥u3u_1\ge u_2\ge u_3u1​≥u2​≥u3​ of TTT\mathcal{T}^{\mathsf{T}}\mathcal{T}TTT,

Tij=Tr ⁣[ρ (σi⊗σj)],Smax⁡(T,h)=2u1+u2\mathcal{T}_{ij}=\mathrm{Tr}\!\left[\rho\,(\sigma_i\otimes\sigma_j)\right],\qquad S_{\max}(T,h)=2\sqrt{u_1+u_2}Tij​=Tr[ρ(σi​⊗σj​)],Smax​(T,h)=2u1​+u2​​

The state can violate the CHSH inequality exactly when Smax⁡>2S_{\max}>2Smax​>2; quantum mechanics caps Smax⁡S_{\max}Smax​ at the Tsirelson bound 222\sqrt{2}22​ ≈ 2.828. The Bell-nonlocal region and its boundary are

Ω={(T,h): Smax⁡(T,h)>2},∂Ω={(T,h): Smax⁡(T,h)=2}\Omega=\{(T,h):\,S_{\max}(T,h)>2\},\qquad \partial\Omega=\{(T,h):\,S_{\max}(T,h)=2\}Ω={(T,h):Smax​(T,h)>2},∂Ω={(T,h):Smax​(T,h)=2}

The reference landscape is an exact-diagonalization grid over T/J∈[0.02,3]T/J\in[0.02,3]T/J∈[0.02,3] and h/J∈[0,3]h/J\in[0,3]h/J∈[0,3]. In this model, at low temperature and low field, the singlet ground state gives Smax⁡S_{\max}Smax​ close to 2√2. A ground-state level crossing at h/J=2h/J=2h/J=2 switches the ground state to the fully polarized product state, for which Smax⁡S_{\max}Smax​ = 2.

The last consequence is the geometry that matters here: beyond h/J≈2.4h/J\approx 2.4h/J≈2.4 the boundary continues only at very low temperature (the 40 reference boundary points with h/J≥2.5h/J\ge 2.5h/J≥2.5 lie at T/JT/JT/J ≤ 0.054), where Smax⁡S_{\max}Smax​ sits close to the threshold. This is the high-field wedge.

  1. Physical simulatorExact diagonalization of the dimer

  5. Boundary extractionPredicted Smax = 2 contour points

Models
Random Forest (300 trees); MLP (2-32-32-1, Tanh, Adam, lr 0.01, 400 epochs, MSE); physics-aware MLP (same network; boundary-weighted MSE plus a Tsirelson penalty on Smax⁡S_{\max}Smax​ > 2√2, λT = 1)
Sampling
Uniform (log-uniform in T, uniform in h); boundary-aware (a pilot scan, counted against the budget, locates the approximate boundary, then samples concentrate near it)
Budgets
N ∈ {50, 100, 250, 500, 1000, 2500}
Seeds
Main sweep 42–51 (10 seeds); ablation 42–61 (20 seeds)
Test grid
One fixed 240×240 exact grid, never regenerated per run
RMSE
Root-mean-square error of predicted Smax⁡S_{\max}Smax​ over the test grid
Region disagreement
Area-weighted measure of the symmetric difference between the true and predicted regions Smax⁡>2S_{\max}>2Smax​>2
Hausdorff dH
Worst-case distance between the true and predicted extracted boundary point sets, in (T, h) coordinates
Boundary displacement
Distance from a true boundary point to the nearest predicted boundary point
Bound violations
Point-level check of displacement ≤ ε/m (see the theorem section) and the rate of predictions above 2√2

Pointwise accuracy is not boundary fidelity

Random Forest can have strong pointwise performance and still recover the Bell boundary poorly. Its RMSE falls monotonically with budget, while its mean Hausdorff error does not: it rises from 0.547 at N = 100 to 0.970 at N = 2500 (0.820 at N = 50). The MLPs' Hausdorff errors fall and then plateau at roughly 0.2.

This shows that RMSE alone can miss worst-case geometric errors in this setting. It does not show that RMSE is uninformative: RMSE is clearly related to region disagreement (below), and the boundary metric is a worst-case one, so it is sensitive to a single missing segment.

The high-field boundary wedge

The true boundary has a branch for h/J≥2.5h/J\ge 2.5h/J≥2.5 that lies at very low temperature (red points in the figure). A predicted boundary is counted as having recovered the wedge if it contains at least one point with h/J≥2.5h/J\ge 2.5h/J≥2.5. That threshold, the midpoint between the level crossing at h/J=2h/J=2h/J=2 and the domain edge h/J=3h/J=3h/J=3, was fixed in config.json before the 10-seed outcomes were inspected, and is applied identically to all models.

10-seed replication

The original experiment used 3 seeds and 108 runs. It was extended to 10 seeds and 360 main runs with the same physical simulator, the same fixed test grid, the same model architectures and hyperparameters, and the same evaluation code. According to the repository README, the only change to the design is the seed list (42–44 became 42–51). The aim is to check whether the qualitative pattern persists across independent random seeds.

At N ≥ 1000 the outcome is identical across all seeds for every model: RF always misses, both MLPs always recover. At N = 2500 the RF Hausdorff error has a standard deviation of 0.070 across seeds, small compared with the roughly 0.8 gap to MLP (data), so the RF–MLP gap is not driven by a few outlier seeds.

Boundary-displacement theorem

Theoretical statement

Informally: if a surrogate f^\hat ff^​ is uniformly within ε of the true landscape fff near a boundary point x0, and fff crosses the threshold transversally there, with ∣∂Tf(x0)∣≥m>0|\partial_T f(x_0)|\ge m>0∣∂T​f(x0​)∣≥m>0, then the surrogate's threshold boundary passes within distance of order ε/m of x0:

d ⁣(x0,∂Ω^)  ≲  εm,ε bounding ∣f^−f∣ near x0d\!\left(x_0,\partial\hat\Omega\right)\;\lesssim\;\frac{\varepsilon}{m},\qquad \varepsilon\ \text{bounding}\ |\hat f-f|\ \text{near}\ x_0d(x0​,∂Ω^)≲mε​,ε bounding ∣f^​−f∣ near x0​

The exact hypotheses and constants are those of the paper; this page reports only the point-level check implemented in the repository.

Empirical validation of the stated bound

For each of 50 (configuration, seed) evaluations, the check compares each testable true-boundary point's displacement to the predicted boundary against εloc/m. Here m = |∂T Smax⁡S_{\max}Smax​| from finite differences of the reference grid, εloc is the largest absolute error within ±5 grid cells, and only points with m ≥ 0.05 are testable (159 of 210 boundary points).

7,934 of 7,950 checks (99.80%) satisfy the bound. The other 16 apparent violations are concentrated in a few evaluations at 156–158 of 159. The repository report attributes a representative case, exceeding the bound by 0.0014 (about 11% of a grid cell), to finite-difference and grid discretization error; that attribution was checked on one example.

Empirical checks are not a proof. A high fraction of satisfied point-level checks on one simulator supports the stated bound in this experiment; it does not establish the theorem, and the bound is not satisfied in every check.

Tsirelson-aware loss ablation

A separate ablation uses 20 seeds and 80 runs (four loss variants at N = 500 with boundary-aware sampling). p-values are Mann–Whitney tests against the data-only baseline; the boundary and Tsirelson-rate p-values are adjusted with the Benjamini–Hochberg (BH) procedure across six tests (ablation_bh_correction.csv).

The loss significantly reduced bound violations, while the study did not find a significant improvement in boundary fidelity. The Hausdorff error is 0.194 with the data-only loss and 0.207 / 0.190 with the Tsirelson penalty / both terms, and none of these differences is significant. This null result is reported as a null result; it is not evidence that the loss helps or hurts boundary fidelity.
